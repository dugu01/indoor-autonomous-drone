S2.3 known-boundary policy replay add-on

This add-on changes replay/backtest tools only. It does not modify coupled
flight, mapping, planning, estimation, control, or lifecycle source.

Copy both .m files into the existing replay-instrumented S2.3 development
folder, replacing replay_perception_log_S2_3.m, then run the commands in
NEXT_GATE_KNOWN_BOUNDARY_REPLAY.md.
