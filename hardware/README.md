# Hardware Directory

Contains hardware-related resources for the project.

Examples:
- CAD models
- Mechanical designs
- PCB schematics
- Wiring diagrams
- BOM (Bill of Materials)
- Embedded firmware
- Assembly instructions

Include sufficient information for reproducing the hardware setup where possible.

## Contents

| Path | Contents |
| ---- | -------- |
| `firmware/arduino/` | Arduino / companion-MCU firmware (populated during hardware integration). |

The target airframe is a DJI F450 (450 mm diagonal). CAD meshes used for the
simulation flight animation are in
[`../simulation/S2_visual_slam/assets/F450/`](../simulation/S2_visual_slam/assets/F450).
