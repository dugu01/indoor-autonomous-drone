Reason for v6
-------------
The user's v5 run produced:
- benchmark seed 0: PASS, clean Tier-3 decoy present;
- seed 1: mission/safety/truth/target-selection PASS, but cleanDecoyFound=false.

v5 treated clean-decoy appearance as mandatory in every seed, so it stopped at
seed 1. That duplicated the benchmark-activation requirement inside a stochastic
robustness sweep.

Corrected layered semantics
---------------------------
1. Controlled adversarial policy contract remains mandatory:
   IG_D > IG_T, raw utility_D > utility_T, clean safety-feasible Tier-3 decoy,
   Tier-1 target selected.
2. Fixed physical benchmark seed (default seed 0) must instantiate a clean
   Tier-3 decoy and select the Tier-1 target in the same recorded decision.
3. Every robustness seed must still pass mission, target selection, execution,
   hard safety, truth isolation, and zero irrelevant selection.
4. Clean-decoy non-appearance alone is not a robustness failure.
5. Whenever a clean decoy appears in any robustness seed, its decision evidence
   is checked conditionally for target-priority.
